Security
--------
* Updated Pillow to 12.3.0, urllib3 to 2.8.0, and certifi to 2026.10.19 in `uv.lock`, addressing 17 Dependabot alerts while preserving Python 3.10 support.
* Raised the Pillow and urllib3 minimum versions to these patched releases. 41 Pillow alerts remain: their first patched release is Pillow 13.0.0, which requires Python 3.11 or later.
